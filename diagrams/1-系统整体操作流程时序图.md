sequenceDiagram
    actor U as User
    participant G as MainWindow
    participant M as SimManager
    participant T as TrajGenerator
    participant V as Charts/Table

    U->>G: Set params, click Generate
    G->>M: generateTrajectory(params)
    M->>T: Background thread compute
    T->>T: Ruckig OTG planning
    T-->>M: Result(points, duration)
    M-->>G: trajectoryGenerated
    G->>V: Load curves and data table

    U->>G: Click Play
    G->>M: startSimulation
    M->>M: Start QTimer, state to Running
    loop ~60Hz tick
        M->>M: Interpolate flight state
        M-->>G: realtimeStateUpdated
        G->>V: Update charts and status
    end

    U->>G: Pause or Stop or Reset
    G->>M: pause or stop or reset
    M->>M: FSM state transition
